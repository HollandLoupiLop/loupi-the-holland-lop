# Loupi Gang — référence

## Plateforme de marque
- Positionnement : streetwear premium **brodé** (pas de gros prints criards), discret, « Quietly Different. ».
- Fulfilment Printful (POD, pas de cut-and-sew) → la qualité perçue vient du choix des blanks (heavyweight), de la broderie et des visuels.
- Ordre de lancement « First10 » et DA : voir `design/01_plateforme_DA.md` cité dans le doc contexte Drive (à relire, ne pas deviner les SKUs).

## Gabarit collection
- Nom + idée en 1 phrase · 4 à 8 pièces · palette (3 couleurs max) · emplacement broderie (poitrine gauche, nuque, manche) · prix cible (marge ≥ 50 % après coût Printful + Shopify + shipping) · histoire de lancement.

## Gabarit fiche produit Shopify
```
Titre : <Nom pièce> — <couleur> (≤ 60 car.)
Accroche : 1 phrase sensorielle
Puces (5 max) : matière & grammage (donnée Printful), coupe, broderie, entretien, délai de fabrication
Guide des tailles : tableau US (Printful) + conseil de coupe
Expédition/retours : délais Printful réels, politique de retour POD
SEO : meta title ≤ 60, meta description ≤ 155, alt images descriptifs, handle court
Schema Product (seo-schema) : price, availability, brand = LOUPI GANG
```

## Contraintes Printful (vérifier sur la fiche produit Printful)
- Broderie : nombre de couleurs de fil limité, zone max, pas de dégradés fins ; texte ≥ ~0,25 in de hauteur.
- Délais de production + expédition à afficher honnêtement.
- Mockups : utiliser les mockups Printful ou photos réelles ; pas d'image IA présentée comme photo du produit réel.
