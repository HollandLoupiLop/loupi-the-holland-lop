## Workflow
1. Identifier la marque et la tâche (branding / collection / fiche / lancement / listing).
2. Lire le contexte Drive à jour (rechercher le doc « loupi-gang — context » ; rechercher « Aventures de Loupi » pour les livres). Champs « UNKNOWN — to confirm » = ne pas inventer.
3. Produire le livrable avec le gabarit de la référence.
4. Appeler les skills installées plutôt que réinventer : `copywriting` (fiches), `product-marketing` (positionnement), `launch`, `emails`, `social`, `influencer-marketing`, `ad-creative`, `seo-ecommerce` + `seo-schema` (Shopify), `image` (visuels), `video-production-director` (Reels/TikTok).
5. **Aucune publication** (Shopify, KDP, réseaux) ni dépense : livrer des brouillons ; exécution après ligne `Approvals` (skill `ai-group-coo`). Toute mise en ligne de thème/page : QA visuelle avant/après.

## Garde-fous
- Allégations vérifiables uniquement (matières, grammage, origine = données Printful réelles du produit choisi).
- Pas de marques/personnages tiers, pas de logos sportifs, pas de paroles de chansons (risque IP + refus Printful/KDP).
- US : FTC (divulgation influence), California Prop 65 si applicable, tailles US.
- Jeunesse (KDP) : pas de collecte de données enfants, contenu adapté à l'âge déclaré.
